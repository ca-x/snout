## snout 0.3.0

### Native desktop

- Add a Rust-only NSH workbench for Windows, macOS, and Linux, alongside the existing CLI/TUI.
- Cover scheme selection, all/component updates, model patches, skins, candidate count, settings, exclusions, diagnostics, Rime setup, and JSON/completion export.
- Run operations on a background worker with progress, cancellation, explicit user-data/hook confirmation, and masked credentials.
- Share update dispatch, configuration validation, status checks, reports, appearance capabilities, and safe persistence across frontends.
- On window close, request cancellation and wait outside the event loop for the worker and running hooks to finish; do not abandon installation work.

### Fixes and hardening

- Merge PR #6 to resolve issue #5: cache Windows TUI configuration/engine discovery and redraw only when state changes. Thanks to @lujfsd for the report and contribution.
- Restore terminal modes on setup failures and normal exit; keep theme resolution free of configuration I/O.
- Validate resumed/parallel HTTP ranges and payload sizes, and stop/drain parallel workers before retrying or falling back.
- Keep Mint updates from filtering/deleting unrelated files in the live Rime directory.
- Stage and normalize archives before merging into existing installations; reject archive links and destination child symlinks before writing outside the selected root.
- Exclude the source directory from engine synchronization, including canonicalized aliases.
- Make model checksums authoritative even when cached release metadata has not changed.
- Repair missing Ice/Frost/Mint installation files and Wanxiang dictionaries despite matching cache records.
- Adopt checksum-valid existing models into version records without downloading them again.
- Preserve Fcitx5 optional rounding state across installation and readback.
- Validate candidate sizes in the shared core; preserve configuration, YAML patch content, permissions, and symlinks through atomic writes and rollback.
- Restore the exact original model-patch bytes and file existence if configuration persistence fails, including custom grammar settings and comments.
- Fail initialization with a nonzero exit status when installation or explicitly requested Rime setup fails, rather than reporting success.
- Pass hook script paths as single arguments to `sh`, including paths containing spaces, without shell command interpolation.

### Downloads

The five existing CLI artifact names remain unchanged. Native desktop packages are additional `snout-desktop-v0.3.0-*` assets:

- Linux x86_64: GNU dynamically linked archive; GTK 4.14+ required. Includes `bin/` and a desktop entry.
- macOS Intel / Apple Silicon: archives containing an unsigned `.app`.
- Windows x86_64: ZIP containing the native executable.

`SHA256SUMS` covers all CLI and desktop assets. Verify checksums before opening unsigned desktop packages and use the operating system's normal authorization controls. The existing `snout-bin` AUR package continues to ship CLI/TUI only.

CLI/TUI and desktop share the existing configuration. Avoid concurrent updates from separate processes. Existing CLI options, JSON schema, and direct-action exit codes remain compatible; failed `--init` now correctly exits unsuccessfully.
