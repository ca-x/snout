# snout v0.4.0

## 原生桌面端重新设计

- 新的侧栏导航、矢量图标和页面工具栏；概览展示当前方案、组件版本和输入引擎状态。
- 13 种输入方案改为可折行的选择卡片，当前选择带明确勾选标记。
- 外观页新增候选窗口布局预览，修改数量即可查看效果，应用后才写入 Rime。
- 设置按常规、下载网络、自动化分组，在宽窗口中并排排列。
- 未保存修改显示固定保存/还原栏，切换页面仍保留草稿。
- 确认操作使用原生模态层，支持 Escape 取消；保留用户数据策略和钩子提示。
- 新增 Command/Ctrl+1–5 切页、Command/Ctrl+S 保存快捷键。
- 统一浅色/深色语义主题；按钮、选择、开关和内容展开提供轻量动画反馈，并尊重系统减少动态效果设置。

## 下载与安装

桌面包支持 Linux x86_64、macOS Apple Silicon / Intel、Windows x86_64。
Linux 桌面端需要 GTK 4.14+；macOS 和 Windows 桌面包尚未签名。
Arch Linux 可通过 `snout-desktop-bin` 安装。CLI/TUI 仍是独立的 `snout-bin` 包。

候选预览仅演示布局与数量，实际字体和配色由输入引擎主题决定。
