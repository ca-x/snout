# snout v0.4.1

## 桌面品牌图标

- 使用用户设计的透明蜗牛 Logo，替换桌面侧栏的文字占位图标。
- 根目录与桌面端 README 展示同一份 Logo 原稿。
- Linux 桌面包提供 256 / 512 像素 hicolor 图标，应用菜单和窗口使用统一应用标识；AUR 安装同步包含图标。
- macOS `.app` 包含多尺寸 ICNS 图标，Windows 可执行文件嵌入多尺寸 ICO 图标。

桌面包支持 Linux x86_64、macOS Apple Silicon / Intel、Windows x86_64。
Linux 需要 GTK 4.14+；macOS 和 Windows 桌面包尚未签名。
Arch Linux 可通过 `snout-desktop-bin` 安装；CLI/TUI 仍是独立的 `snout-bin` 包。
