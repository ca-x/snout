# snout v0.5.4

## 一眼看懂哪些需要更新

- 桌面概览与 TUI 主菜单显示明确的组件状态：已是最新、需要更新、未安装、尚未检查、检查失败、不适用。
- 桌面启动后后台检查组件版本，显示本地与最新版本；已是最新的组件不再提供可点击的更新按钮，检查失败可重试。
- 状态复用真实更新规则，考虑文件是否存在、版本标识、hash 和更新时间；相同版本标签不再掩盖更新，离线不会误报最新。
- 新增 `snout status` / `snout status --json`，只读检查方案、词库与模型，不安装、不改配置；检查失败返回非零退出码。

## 安装与更新步骤时间线

- 桌面和 TUI 使用组件时间线展示「检查 → 下载 → 校验 → 安装与应用」，活动步骤带 loading 反馈，桌面尊重减少动态效果偏好。
- 真实事件驱动步骤状态；无需执行的步骤跳过，失败、取消和完成分别呈现，不伪造下载或校验进度。
- 桌面原始日志默认折叠在诊断日志中，JSON 结果仍可查看与导出。桌面和终端程序自更新也接入真实步骤反馈。
- 保持 AUR / pacman 安装的程序自更新禁用策略，不影响方案、词库和模型更新；保持预览模式的核心副作用隔离。

## 验证范围

- 覆盖共享状态、时间线失败/取消、只读 CLI、双语桌面交互、深浅主题与减少动态效果的 headless 回归。
- 原生 Linux 编译与测试单独执行。当前显示环境未取得有效窗口截图，不将其视为完成视觉验收；Windows/macOS 实机视觉与升级仍需对应平台验证。
