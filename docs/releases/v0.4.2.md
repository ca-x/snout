# snout v0.4.2

## GitHub 认证与限流提示

- 桌面端、CLI、TUI 统一支持：显式配置 Token → `GH_TOKEN` → `GITHUB_TOKEN` → 本机已登录的 `gh` → 匿名访问。
- 无需安装 gh：可在桌面设置填写 Token，或通过环境变量提供；现有 `--github-token` 参数继续支持。
- 自动读取的凭据只保留在内存中，不回写配置，不再把 GitHub Token 发送给 CNB 镜像。
- gh 不存在、未登录或读取超时会回退匿名访问，不启动交互式登录。
- 改善 401 / 403 / 429 错误提示：区分认证失败、额度耗尽和访问拒绝，显示响应头中的恢复时间与等待时间；这些错误不再立即重试。
- 桌面设置与 CLI 帮助补充认证顺序说明，保留 v0.4.1 的 Logo 与平台应用图标。

桌面包支持 Linux x86_64、macOS Apple Silicon / Intel、Windows x86_64。
Linux 需要 GTK 4.14+；macOS 和 Windows 桌面包尚未签名。
Arch Linux 桌面包为 `snout-desktop-bin`，CLI/TUI 为 `snout-bin`。
