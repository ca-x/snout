# snout v0.5.3

## 程序自更新

- 桌面便携版启动时检查程序新版；「设置 → 程序更新」支持手动检查、查看说明，并在确认后下载、校验、替换程序及重启。
- CLI 新增 `snout self-update` / `snout self-update --check`，仅检查程序更新；`snout self-update --yes` 明确确认后安装，`--json` 支持脚本使用。
- TUI 启动时后台检查程序新版，主菜单新增 `U 程序更新`，支持查看、确认安装、取消下载；安装完成后退出并重新运行即可使用新版。
- 程序更新校验官方来源、应用标识、SemVer、下载大小和 SHA-256；网络检查与下载可以取消，最终替换不会覆盖 Rime 数据及用户配置。

## 包管理边界与后续发布

- AUR 的 `snout-bin` 和 `snout-desktop-bin` 均安装包管理标记，完全禁用程序自更新。系统安装路径即使可写或以 root 运行，也不会绕过限制；请通过 AUR 助手或包管理器升级。
- 原有 `--update`、方案、词库和模型自动更新保持原来的行为，与程序自更新相互独立。
- 后续正式 Release 自动生成覆盖 5 个终端二进制与 4 个桌面包的 `latest.json`，在所有更新载荷上传后才发布清单。
- Windows 桌面 ZIP 改为单个便携目录；桌面便携版需要保留完整目录，单独复制可执行文件会禁用自更新。
- 桌面编译需要 Rust 1.97+；NSH UI/engine 仍为 0.4.0，独立更新模块使用 `nsh-updater` 0.5.0。
