# snout v0.5.5

## 选方案、看版本，再安装

- 桌面输入方案页先列出六个系列和各自的来源。选中万象后可搜索标准版和九种 Pro 辅助码，来回比较其他方案时也能回到刚选的版本。
- 底部操作栏和安装确认框都显示完整方案名。确认框列出安装目录，并在有待保存设置时提醒你。
- 从启用了语言模型补丁的方案切换到极点五笔 86 或智能 ABC·改时，Snout 会保留模型偏好，跳过对这两个方案的补丁写入。

## 直接预览每页候选数

- 打开「外观」即可看到当前方案和已保存的候选数。点选 1–9 中的数字就能比较布局，确认应用后才会写入设置。
- 在「外观」按 Alt+1–9 选数量，Alt+0 选「跟随方案」，Alt+Enter 应用。macOS 使用 Option 键。
- 选「跟随方案」可以恢复默认。预览里的五个词标为示例，实际数量由方案决定。
- 已有配置里带引号的候选数也能读回。文件损坏时，「外观」会显示读取错误，修复文件后点「重新读取」即可继续。
- 安装结束后，完整时间线留在「活动」。切到其他页面会回到页首，空闲时收起进度条和取消按钮。
