# snout v0.5.0

## 输入方案

- 桌面、CLI 与 TUI 新增极点五笔86（`jidian` / `wubi86-jidian`）和智能 ABC·改（`abcm` / `abc`），共 15 个方案选项。
- 两者按上游 master 提交更新，下载固定到所检查的 commit；智能 ABC 从 rime/ 提取方案与 Lua，并在需要时补齐 luna_pinyin 词典。
- 保留用户和平台自定义皮肤，将新方案加入切换菜单；词库随方案安装，不提供独立词库更新或万象模型补丁。

## Linux Fcitx5 主题

- 桌面改用可筛选虚拟列表，以内置、在线及已安装标签区分来源。
- 从 GitHub fcitx5-theme 和 fcitx5-skin topic 分页获取仓库，按仓库 ID 去重。
- 新增 CLI --list-fcitx5-themes、--fetch-fcitx5-theme OWNER/REPO，均支持 --json；TUI 可选择已获取主题。
- 在线导入只提取可直接使用的主题文件，隔离不同仓库与变体，不运行安装脚本。获取后仍需明确选择亮暗主题并应用。
- 无 theme.conf 的生成型主题明确提示，并提供仓库入口。搜索与导入支持取消，使用共享 GitHub 认证。

## 平台适配

- 桌面按当前引擎隐藏不支持的皮肤面板与补丁设置；CLI 帮助隐藏不适用的平台主题参数。
- 保留既有候选数量设置、主题支持时显示的可选圆角、双语标签和确认流程。
